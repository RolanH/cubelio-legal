# CubeGym – Datenschutz / Privacy

Dieses Repository enthält die statischen Datenschutzseiten von CubeGym auf Deutsch und Englisch.
Die Texte sind Entwürfe für die interne Testphase und wurden nicht anwaltlich geprüft.
Die zugrunde liegende Dokumentation wird nicht öffentlich geführt; dieses Repository enthält die für Leser bereinigten Fassungen.
Verantwortlicher und Kontakt werden vor dem öffentlichen Start ergänzt.
